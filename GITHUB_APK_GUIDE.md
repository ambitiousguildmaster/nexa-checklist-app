# NEXA — Free GitHub APK Builder

This is the original NEXA Flutter project with a GitHub Actions APK workflow added.

## Build
1. Create a GitHub repository.
2. Upload this project.
3. Open **Actions**.
4. Choose **Build NEXA APK**.
5. Tap **Run workflow**.
6. Open the completed run.
7. Download the `NEXA-release` artifact.

No Flutter or Android SDK is required on your phone. GitHub's runner performs the build.

The workflow also creates a GitHub Release when started manually.
