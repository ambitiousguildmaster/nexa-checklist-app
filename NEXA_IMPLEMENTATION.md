# NEXA Implementation Map

The UI follows the Figma NEXA design: Dashboard, Today, Task Detail, Add Task, Projects, Insights and Settings.
The current build wires the main flows into live Flutter state and local persistence.

Next production layers can attach to the same Task model:
- OS-level scheduled notifications
- recurring-task scheduler
- calendar integration
- AI Focus recommendations
- cloud sync/auth
- richer task detail/subtasks
- accessibility/reduced-motion controls
