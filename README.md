# NEXA Checklist App

Flutter implementation of the NEXA glassmorphism checklist design.

## Included
- Glassmorphism dark UI with blurred/translucent containers
- Dashboard and progress
- Today list
- Search and filters
- Task completion and swipe-to-delete
- Add task dialog
- Project organization
- Priorities
- Reminder/repeat fields
- Insights/streak view
- Settings
- Local task persistence with SharedPreferences
- Responsive mobile-first Flutter layout

## Run
```bash
flutter pub get
flutter run
```
